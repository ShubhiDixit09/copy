# DHARTI Changelog: v0.9.0 - Google Drive Decoupled Object Storage & Neon DB Indexing

**Release Tag**: `v0.9.0`  
**Date**: 2026-09-07  
**Type**: Minor (Hybrid Cloud Storage Architecture)  
**Primary Architect**: Antigravity  

---

## 1. Executive Summary

Version `v0.9.0` implements the hybrid storage architecture specified by the user: storing indexes, SHA-256 cryptographic hashes, and relational metadata in **Neon Serverless PostgreSQL**, while streaming and storing large evidentiary files (high-resolution Cadastral Survey maps, Gazette notification PDFs, High Court speaking order PDFs, Panchnama photos) in **Google Drive**.

---

## 2. Detailed Changes

### 2.1 Added

1. **Google Drive Integration Client (`scripts/gdrive_client.py`)**:
   - Built on `google-api-python-client` (v3).
   - Dual-mode authentication:
     - **OAuth2 Desktop Consent Flow**: via `credentials.json` -> `token.json`.
     - **Google Cloud Service Account**: via `service_account.json` or `GOOGLE_APPLICATION_CREDENTIALS`.
   - Automatic creation and resolution of root evidence folder (`DHARTI_EVIDENCE_VAULT`).
   - Resumable file upload with automated SHA-256 checksumming and metadata extraction.

2. **Connection Verification Tool (`scripts/test_gdrive_connection.py`)**:
   - Tests credentials availability, authenticates with Google Drive v3, resolves the vault folder ID, and lists files.
   - Provides an interactive onboarding prompt when credentials are not yet supplied.

3. **Hybrid Storage Pipeline (`scripts/upload_to_gdrive_and_neon.py`)**:
   - Streams original large files to Google Drive.
   - Stores file ID, MIME type, file size, web links, and SHA-256 hash in the `evidence_documents` table in Neon PostgreSQL.
   - Automatically writes a bitemporal audit event to `bitemporal_events` in Neon DB.

4. **Relational Schema Updates (`scripts/init_neon_db.py`)**:
   - Added `evidence_documents` table with foreign keys linking to `projects` and `parcels`.
   - Added indexes on `parcel_id` and `sha256_hash`.

5. **Security & Secrets Protection (`.gitignore` & `.env.example`)**:
   - Hardened `.gitignore` to prevent committing `credentials.json`, `service_account.json`, `token.json`, `*.pem`, and `*.key`.
   - Updated `.env.example` with Google Drive configuration variables (`GDRIVE_CREDENTIALS_PATH`, `GDRIVE_TOKEN_PATH`, `GDRIVE_VAULT_FOLDER_ID`).
