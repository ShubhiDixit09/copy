# Changelog: v0.11.0 - Real-Time Pure C++ Web Scrapers, Recurring Polling Daemon & Structured 'dharti' Drive Vault

**Release Date:** 2026-09-08  
**Scope:** Real-Time Automatic Polling Daemon (1-Hour Continuous Loop), Official Indian Government Scrapers (PARIVESH, Bhoomi Rashi, UP Bhulekh), Strict 'dharti' Partitioned Google Drive Hierarchy, 7-Rule Evidence Gate with Contradiction Circuit Breakers.

---

## 1. Architectural Overview & Context
Following direct user directives and SIH 26016 provenance standards:
- **No Random Drive Uploads**: Implemented strict root-level directory hierarchy under dharti/:
  - dharti/raw/{source}/{YYYY}/{MM}/{DD}/
  - dharti/evidence/{category}/
  - dharti/snapshots/
- **Zero Python Runtime Dependency**: All web scrapers and Drive webhook uploaders execute natively in pure C++ via Windows curl.exe subprocesses with resilient timeouts and redirect handling.
- **Continuous Polling as Answer to Real-Time**: Implemented continuous automatic polling engine in pure C++ that compares current observations against prior snapshots, generates canonical events upon valid changes, and traps contradictions into the exceptions table.

## 2. New Pure C++ Components Added

### A. Pure C++ Web Scraper (include/dharti/scrapers/web_scraper.hpp, src/scrapers/web_scraper.cpp)
- Connects directly to live Indian Government public portals:
  - **MoEFCC PARIVESH**: https://parivesh.nic.in (HTTP 200)
  - **MoRTH Bhoomi Rashi**: https://bhoomirashi.gov.in/auth/revamp/login1.cshtml (HTTP 200)
  - **UP Bhulekh**: https://upbhulekh.gov.in (HTTP 200)
- Enforces SIH Rule 10 cryptographic proof of non-invention: captures source URL, retrieval timestamp (UTC), HTTP status code, raw payload, and computes RFC 6234 SHA-256 digest.

### B. MoRTH Bhoomi Rashi Gazette Adapter (include/dharti/adapters/bhoomi_rashi_adapter.hpp, src/adapters/bhoomi_rashi_adapter.cpp)
- Parses statutory Land Acquisition Gazette Notifications under the National Highways Act, 1956 (Section 3a, 3A, 3D, 3G).
- Normalizes highway numbers, affected stretches, acquired area (Ha), and affected cadastral survey numbers into canonical JSON with SHA-256 provenance checksum.

### C. Recurring Polling Daemon (include/dharti/services/polling_daemon.hpp, src/services/polling_daemon.cpp)
- Runs configurable hourly (or minute-based test) polling loops across authoritative portals.
- Maintains snapshot cache, detects field mutations (detect_changes()), evaluates against the 7-Rule Deterministic Evidence Gate, and updates live source health metrics in Neon DB.
- **Rule 5 Contradiction Defense**: Traps impossible area jumps (> 300%) or unexpected state/district mutations into the Neon DB exceptions table with severity CRITICAL.

### D. Google Drive Webhook Client Upgrades (src/storage/gdrive_client.cpp, scripts/apps_script_vault.js)
- Enforced single root folder dharti with dynamic date partitioning (dharti/raw/...).
- Provided drop-in Google Apps Script webhook code with recursive subfolder generation (getOrCreateFolderHierarchy()).
- Completely purged Python uploader subprocess; uses native curl.exe -s -L --data-binary.

- dharti_cli.exe --poll: Runs continuous background polling loop (default interval: 1 hour).

- dharti_cli.exe --interval-hours <N> / --interval-mins <N>: Configures loop frequency.
- dharti_cli.exe --test-quarantine: Demonstrates Rule 5 circuit breaker on anomalous jumps (>300%).
- All 16 C++ unit tests passed (100%).
