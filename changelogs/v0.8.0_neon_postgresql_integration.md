# DHARTI Changelog: v0.8.0 - Neon Serverless PostgreSQL Database Integration

**Release Tag**: `v0.8.0`  
**Date**: 2026-09-07  
**Type**: Minor (Database & Cloud Persistence)  
**Primary Architect**: Antigravity  

---

## 1. Executive Summary

Version `v0.8.0` integrates DHARTI with **Neon Serverless PostgreSQL** cloud database endpoint (`ep-frosty-butterfly-ax2quyii-pooler.c-4.us-east-2.aws.neon.tech`). It establishes the `.env` secret configuration (strictly excluded from Git via `.gitignore`), provides a safe `.env.example` template, creates database connectivity verification tools (`scripts/test_db_connection.py`), and initializes the core relational schema (`projects`, `parcels`, `ecourts_cases`, `pfms_advices`, `sia_households`, `bitemporal_events`) with authentic Indian land records seeded directly into the cloud database.

---

## 2. Detailed Changes

### 2.1 Added

1. **Environment Configuration (`.env` & `.env.example`)**:
   - Configured `DATABASE_URL` and `NEON_DATABASE_URL` with SSL/TLS parameters (`sslmode=require&channel_binding=require`).
   - `.env` protected against Git leaks via `.gitignore`.
   - `.env.example` provided for developer onboarding.

2. **Connection Verification Tool (`scripts/test_db_connection.py`)**:
   - Tests end-to-end TLS/SSL connectivity to the Neon PostgreSQL cluster.
   - Measures connection latency.
   - Queries server metadata (PostgreSQL 18.6 on AWS us-east-2) and inspects public schema tables.

3. **Schema Bootstrapping & Seeding Script (`scripts/init_neon_db.py`)**:
   - Deploys full relational tables: `projects`, `parcels`, `ecourts_cases`, `pfms_advices`, `sia_households`, and `bitemporal_events`.
   - Adds spatial and chainage indexes (`idx_parcels_chainage`, `idx_parcels_state`, `idx_bitemporal_time`).
   - Seeds authentic Indian administrative records from `data/projects/`, `data/cadastral/`, `data/ror/`, and `data/sia/`.

## 3. Verification & Live Test Evidence

- **Database Connection**: Successfully connected to `neondb` on `ep-frosty-butterfly-ax2quyii-pooler.c-4.us-east-2.aws.neon.tech` over encrypted TLS.
