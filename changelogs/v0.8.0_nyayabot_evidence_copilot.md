# DHARTI Changelog: v0.8.0 - NyayaBot Evidence Copilot

**Release Tag**: `v0.8.0`

**Date**: 2026-09-06

**Type**: Minor (Role-Aware Evidence Interaction)

## Added

- Floating NyayaBot evidence-copilot panel linked to the live DHARTI browser data store.
- Deterministic intent routing for blockers, PCI, family inclusion, payment, audit, policy and grievance queries.
- Evidence citations, source timestamps, confidence labels and privacy-preserving Answer Receipts.
- Role policies for CALA, Ministry, State, PIU, Auditor and verified affected-family access.
- Citizen privacy mode that hides the official workspace and requires case verification for personal records.
- ShieldAI-style prompt-injection and protected-data refusal gate.
- Human-reviewable action drafts with duplicate-write prevention and no direct domain-state mutation.
- JavaScript tests covering grounding, privacy, safety, PCI, inclusion and the no-autonomous-write invariant.
- Detailed production integration path for the existing FastAPI, ShieldAI, ChromaDB and Ollama/Gemma NyayaBot stack.

## Preserved invariants

- NyayaBot cannot decide ownership, entitlement, compensation or court outcomes.
- NyayaBot cannot mark a parcel construction-ready or issue a payment.
- Authoritative state remains in DHARTI; the copilot only explains cited results and drafts review actions.
