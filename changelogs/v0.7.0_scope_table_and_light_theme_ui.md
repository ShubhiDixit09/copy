# DHARTI Changelog: v0.7.0 - Scope of Study Table, Suggested Technologies & Light Theme Web UI

**Release Tag**: `v0.7.0`  
**Date**: 2026-09-05  
**Type**: Minor (Documentation & Web UI Presentation)

## 1. Executive Summary

Release `v0.7.0` responds directly to the National Land Acquisition & Management System study specifications by formalizing the **Scope of Study** table and the **Suggested Components-Wise Technology** table into the living specification, and delivering a modern, production-grade **Light Theme Web UI** (`web/`) with interactive Leaflet.js Cadastral GIS mapping, real-time manual testing sandbox, statutory SLA monitoring, customizable MIS reporting, and live PCI mathematical simulation.

---

## 2. Detailed Change Matrix

### 2.1 Added

1. **Section 1.4: Scope of Study Table (`docs/srs/01_introduction_and_scope.md`)**:
   - Comprehensive matrix detailing all 9 lifecycle phases (Proposal Submission to Final Possession Handover).
   - Tracks the 15 statutory parameters (Land proposed/acquired, notifications issued, awards declared, compensation assessed/disbursed, possession status, R&R progress, affected & displaced families, project/state progress, timeline adherence).
   - Maps institutional stakeholders (Central Ministries, State Revenue, District CALA, NHAI PIU, Beneficiaries) and DHARTI verification outputs.

2. **Section 3.3: Suggested Components-Wise Technology Table (`docs/srs/03_logical_architecture_and_components.md` & `docs/ARCHITECTURE.md`)**:
   - Recommends and justifies technologies across all 6 architectural tiers:
     - Tier 1: HTML5, Vanilla CSS3 Light Theme Design System, Vanilla ES6+ JS, Leaflet.js / OpenStreetMap GIS.
     - Tier 2: ePramaan National SSO, ABAC/RBAC, HMAC-SHA256 PII Tokenization.
     - Tier 3: Pure C++17 Native Control Plane Engine (`dharti_core.dll`), Decoupled State Machines.
     - Tier 4: $O(M \log M)$ Introsort & Interval Merging for PCI, "No Family Invisible" SIA inclusion rules, Deterministic Contradiction Engine.
     - Tier 5: Bitemporal Canonical Event Store with SHA-256 cryptographic chain, PostGIS spatial indexing, Content-Addressable Proof Storage.
     - Tier 6: Federated C++17 adapters for Bhoomi/Bhulekh, BhuNaksha, eCourts CIS, PFMS.

3. **Light Theme Web UI (`web/`)**:
   - `web/index.html`: Modern semantic HTML dashboard with Government of India header, role switcher, live KPI cards, and 6 functional tabs.
   - `web/css/styles.css`: Bespoke light theme design system with slate/indigo color tokens, glassmorphism cards, responsive grids, and print media rules for MIS reports.
   - `web/js/data_store.js`: Encapsulates authentic Indian land records (Bhoomi, eCourts, PFMS, SIA) with an append-only cryptographic ledger.
   - `web/js/pci_engine.js`: Pure JavaScript client-side mirror of the C++ interval merging and bottleneck ranking algorithms.
   - `web/js/map_view.js`: Leaflet.js GIS spatial engine parsing WKT polygon boundaries, color-coding parcels by state machine status, and binding popups.
   - `web/js/test_sandbox.js`: Interactive manual testing sandbox enabling execution of multi-agency audits, Invariant 2/3/4 circuit breakers, court stay vacation, PFMS reconciliation, and continuous frontage recalculation.
   - `web/js/mis_reports.js`: Generates print-ready statutory executive dossiers with national emblem, KPI monitor, cadastral inventory, and signature blocks.
   - `web/js/app.js`: Master application coordinator wiring all components together.

4. **Web UI Launcher (`run_ui.ps1`)**:
   - Automated PowerShell launcher that serves `web/` on port 8080 and opens the user's default browser.
