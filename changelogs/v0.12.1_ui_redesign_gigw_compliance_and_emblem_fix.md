# Changelog v0.12.1: Indian Government Portal UI Visual Alignment & Ashoka Emblem Fix

## Date: 2026-09-08
**Milestone**: GIGW 3.0 Compliance, SVG Responsive Containment, and UI Visual Polish

---

### 1. Overview
This iteration addresses critical visual defects in the web portal presentation. Specifically:
- Fixed an unconstrained SVG dimension bug where `assets/emblem_of_india.svg` expanded to 550px × 877px intrinsic dimensions, dominating the viewport.
- Added explicit SVG attributes (`width="42"` `height="67"`), inline CSS containment rules (`height: 56px !important; width: 36px !important;`), and class rules in `styles.css`.
- Synchronized all CSS rules for the new Government Project Tracker components (`.search-form-grid`, `.form-input-gov`, `.btn-gov-primary`, `.dossier-grid`, `.gov-card`, `.rule-checklist-grid`, etc.).
- Introduced HTTP cache-busting query parameter (`styles.css?v=2.2.0`) to guarantee browser cache invalidation.
- Fully verified via browser subagent across all tabs: Project Search & Live Tracking, Executive Cockpit & GIS Map, Bottleneck Unlock Simulator, Statutory Clocks & SLAs, and Executive MIS Report.

---

### 2. Changes

#### Fixed
1. **Ashoka Lion Capital SVG Sizing**:
   - Updated `web/assets/emblem_of_india.svg` opening tag from `width="550" height="876.55"` to `width="42" height="67"`.
   - Added explicit inline attributes `width="36" height="56"` and `style="height: 56px !important; width: 36px !important; max-height: 56px !important; max-width: 36px !important; object-fit: contain !important; display: block !important; flex-shrink: 0 !important;"` to the `<img>` tag in `web/index.html`.
   - Added strict `.ashoka-emblem-img` CSS rules in `web/css/styles.css`.
2. **Header Layout & Viewport Occlusion**:
   - Constrained `.main-header` to sleek, dignified government header height (~70px), preventing it from covering the viewport.
   - Clean alignment between the 56px emblem and the Ministry title (`सड़क परिवहन एवं राजमार्ग मंत्रालय | Ministry of Road Transport and Highways`) and NHAI agency title.
3. **Form Grid & Dossier Card Formatting**:
   - Re-verified and ensured proper display of 3x2 responsive grid (`.search-form-grid`) with 6 distinct project search fields.
   - Fixed unstyled button defaults with authenticated government theme buttons (`.btn-gov-primary` in `#002147` deep navy, `.btn-gov-warning` in `#e65100`, `.btn-gov-danger` in `#b91c1c`).
   - Verified `.dossier-grid` 2-column layout, monospace SHA-256 hash chips, and direct Google Drive links under `dharti/raw/...`.

#### Changed
- `web/index.html`: Linked stylesheet updated to `css/styles.css?v=2.2.0` for guaranteed cache busting.
- `changelogs/index.md`: Appended entry for v0.12.1.
